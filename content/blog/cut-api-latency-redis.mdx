## Architectural Bottleneck Analysis

Before introducing caching layers, we instrumented distributed traces with OpenTelemetry. The root causes were clear:

- Unindexed foreign key lookups triggering full table scans during peak hours
- N+1 query loops across nested relationships
- Expensive cryptographic session deserialization on every microservice hop
